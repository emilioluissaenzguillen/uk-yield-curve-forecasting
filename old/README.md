# Archive Folder

This folder contains legacy or transitional scripts preserved for traceability during the repository cleanup.

Files here are not part of the main reproducible workflow unless explicitly stated elsewhere in the repository documentation.

Current examples include:

- legacy MATLAB coursework scripts that were replaced by the cleaned workflow in `matlab/`;
- archived R plotting code superseded by the Python plotting script in `python/scripts/`;
- earlier Python experiments and alternative versions kept for reference only.
